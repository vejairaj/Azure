# Microsoft Azure — Learning & Hands-on Projects

## About This Repository

This repository documents my journey from zero Azure knowledge to becoming a skilled Azure Administrator.

I am following a structured learning path focused on Microsoft Azure administration, practical hands-on labs, troubleshooting, and preparation for the **Microsoft Certified: Azure Administrator Associate (AZ-104)** certification.

The objective is to develop practical cloud administration skills rather than relying only on theoretical knowledge.

## Learning Objectives

- Understand cloud computing and Microsoft Azure architecture.
- Manage Azure identities, access, and governance.
- Configure and administer Azure Storage.
- Deploy and manage Azure Virtual Machines.
- Configure Azure networking and connectivity.
- Implement monitoring, backup, and recovery.
- Automate administration using Azure CLI and PowerShell.
- Troubleshoot real-world Azure infrastructure issues.

## Learning Approach

Each topic is studied through:

1. **Learn** — Understand Azure concepts and architecture.
2. **Explain** — Develop the ability to explain concepts independently.
3. **Practice** — Perform hands-on labs in Azure.
4. **Troubleshoot** — Diagnose configuration and deployment issues.
5. **Verify** — Validate resources and expected outcomes.
6. **Document** — Maintain commands, notes and screenshots.
